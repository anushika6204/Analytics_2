# 📊 Analytics_2

A collection of data analytics projects and practice notebooks using **Python (pandas)**, covering sales analysis on the Superstore dataset, product demand data, and string manipulation in pandas.

---

## 📁 Repository Structure

```
Analytics_2/
│
├── Analysis.ipynb                          # Exploratory data analysis notebook
├── End To End Data Analytics Project...    # End-to-end analytics project
├── Historical Product Demand.csv.zip       # Product demand dataset (compressed)
├── Strings in pandas.ipynb                 # String operations in pandas (part 1)
├── Strings in pandas2.ipynb                # String operations in pandas (part 2)
├── Superstore Sales Analysis.docx          # Written report of the Superstore analysis
├── superstore_dataset2011-2015.csv         # Superstore sales dataset (2011–2015)
└── README.md                               # Project documentation
```

---

## 📂 File Descriptions

| File | Description |
|------|-------------|
| `Analysis.ipynb` | Data cleaning, exploration, and visualization of the dataset |
| `End To End Data Analytics Project` | Complete workflow: data collection, cleaning, analysis, insights |
| `Historical Product Demand.csv.zip` | Historical demand data for products (unzip before use) |
| `Strings in pandas.ipynb` | Practice with pandas string methods (`str.lower()`, `str.split()`, `str.replace()`, etc.) |
| `Strings in pandas2.ipynb` | Advanced string operations, regex, and text cleaning |
| `Superstore Sales Analysis.docx` | Report summarizing findings and recommendations |
| `superstore_dataset2011-2015.csv` | Sales data including orders, customers, products, profit, and regions |

---

## 🎯 Objectives

- Clean and preprocess raw sales and demand data
- Perform exploratory data analysis (EDA)
- Identify sales, profit, and demand trends
- Analyze performance by region, category, and customer segment
- Practice text and string handling with pandas
- Present insights in a clear, report-style format

## 🛠️ Tech Stack

- **Language:** Python 3
- **Libraries:** pandas, NumPy, Matplotlib, Seaborn
- **Tools:** Jupyter Notebook, Git, GitHub

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/anushika6204/Analytics_2.git
cd Analytics_2
```

### 2. Install dependencies
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 3. Unzip the demand dataset
```bash
unzip "Historical Product Demand.csv.zip"
```

### 4. Launch Jupyter Notebook
```bash
jupyter notebook
```

Open any `.ipynb` file and run the cells in order.
